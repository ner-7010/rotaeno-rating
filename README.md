# Rotaeno Rating Tracker (ロテーノ レーティング管理ツール)

スマホ向け音楽ゲーム『Rotaeno（ロテーノ）』のスコア記録・レーティング（Rating）計算・BEST 40枠管理・完成度分析・理論値(AP+)記録を、PC・スマートフォン・タブレットのブラウザ上で高速かつ完全無料で動作させるクライアント完結型Webアプリケーションです。

---

## 1. プロジェクト概要と基本アーキテクチャ

- **完全サーバーレス・単一HTML成果物**:
  外部サーバーや専用データベースを契約・構築することなく、全楽曲マスタデータ・計算エンジン・UI・同期ロジックを1つの `index.html` に完全内包。Webサーバーに配置するだけで即座に稼働します。
- **ローカルファースト（完全オフライン動作）**:
  入力したプレイデータや設定はブラウザの `LocalStorage` に自動保存されます。通信環境がないオフライン状態でも即座に起動し、1ミリ秒未満で全指標を高速再計算します。
- **Google スプレッドシート連携（個人クラウド同期）**:
  ユーザー自身のGoogleスプレッドシートをプライベートDBとして活用し、スマホとPC間でワンタップで双方向同期が可能です。専用のGoogle Apps Script（GAS）経由で通信します。
- **管理者の親スプシ（RotaenoDB）からの公式アプデ検出**:
  公式アップデートによる新譜面の追加や定数改定を自動検知し、ユーザーの入力済みスコアを維持したままワンタップで最新マスタに更新できます。
- **PWA・モバイル最適化**:
  スマートフォンでのタッチ操作、ホーム画面追加（PWA）、ダークモード、画面遷移時のスクロール位置復元に対応しています。

## 3. 主要機能と画面構成

### ① 🎵 楽曲一覧タブ (`#viewSongs`)
- **高速リスト描画 & 5種のグループ化ソート**:
  - `デフォルト (`DEFAULT`)`: 初期番号（`initId`）順のフラット表示。
  - `単曲レート順 (`RATING`)`: 実効Rating降順のフラット表示。
  - `ソングパック別 (`PACK`)`: ゲーム内の公式パック順にアコーディオンでグループ化。
  - `タイトル別 (`TITLE`)`: 50音・アルファベット・数字・記号・漢字ごとにグループ化（特殊読み対応）。
  - `バージョン別 (`VERSION`)`: 実装バージョン降順（Ver 2.99.0 〜 Ver 1.0.0）でグループ化。
  - `定数別 (`CONST`)`: レベル帯（Lv.14, Lv.13+, Lv.13...）ごとにグループ化。
  - `スコアランク別 (`SCORE`)`: AP+ (1,010,000点) 〜 F までの12段階公式グレードごとにグループ化。
  - グループ化ソート時は上部に「📂 すべて展開」「📁 すべて折りたたむ」ツールバーが出現。
- **高度な絞り込みモーダル（フローティングFAB `☰ 絞り込み`）**:
  - 画面下部に追従するFABからワンタップでモーダルを開閉可能。有効なフィルター件数がリアルタイムに赤丸バッジで表示されます。
  - **キーワード検索**: 曲名、楽曲ID、パック名、バージョン名での部分一致検索。
  - **難易度マルチ選択**: `I`, `II`, `III`, `IV`, `IV-α` のトグル複数選択（例: IVとIV-αのみ表示）。
  - **定数 / レベル絞り込み**: 下限・上限の範囲指定、および完全一致指定（Lv.10+ 等の中間レベル対応）。
  - **スコア範囲絞り込み**: 下限・上限の範囲指定（上限指定時は未プレイ曲を除外）。
  - **埋め作業用除外フィルター**:
    - `AP+ 除外`: 1,010,000点 / AP+達成済みの譜面を除外。
    - `AP 除外`: AP以上（AP, AP+）の譜面を除外。
    - `FC 除外`: フルコンボ以上の譜面を除外。
    - `EX (100万) 以上除外`: 1,000,000点以上の譜面を除外。
    - `既プレイ除外`: スコア入力済みの譜面を除外し、未プレイ曲のみを抽出。
  - **販売終了曲（削除曲）の表示トグル**: デフォルト表示、OFFで除外。
- **絞り込み条件・並び替えの自動保持 ＆ アクティブ条件バー**:
  - ページをリロードしても検索キーワード、難易度、定数、ソート順、開いていたタブを自動復元。
  - 条件適用時は曲一覧上部に `🔍 絞り込み適用中 (〇件の条件): 全 X曲中 Y曲 表示` バーが表示され、`[✕ 条件をクリア]` ボタンで一括初期化可能。
- **直感的なスコア入力モーダル**:
  - テンキー入力、クイック入力（`1010000 (AP+)`, `1009000`, `1008000 (EX+)`, `1000000 (EX)` 等）、クリア状況ランプ選択。
  - スコア `1010000` 入力時は自動で `AP+` ランプに連動。
  - PCキーボードからの直接数値入力および `Enter` 確定ショートカットに対応。
- **安全な明示的保存フロー（未保存バー）**:
  - スコアやマスタ変更時は即座にLocalStorageを上書きせず、画面下部に浮動する未保存バー（`● 未保存の変更があります`）に件数を集約。
  - 「💾 保存する」で確定保存（スプシ自動同期ON時はスプシへも即時送信）、「破棄」で直前の確定状態へ安全にロールバック。未保存時のページ離脱防止ガード（`beforeunload`）を完備。

### ② 👤 マイページタブ (`#viewMypage`)
3つのサブビューをページ内遷移でスムーズに切り替え可能：

1. **📊 総合進捗・統計 (`stats`)**:
   - **集計対象スコープ切り替え**: 「全難易度 (I〜IV-α)」と「IV・IV-α のみ」をワンタップで切り替え。
   - **総合Rating**: b10（60%）、b11-20（20%）、b21-40（20%）の加重合計値。
   - **理論値Rating**: 全譜面が理論値（1,010,000点）だった場合の理論上限Rating。
   - **完成度（Completion Point）**: 難易度係数・スコア・ランプに応じた完成度スコアの合計値および達成率（%）。
   - **クリアランプ別集計**: AP+, AP, FC, CLEAR, FAILED, 未プレイ の各曲数カウントと内訳バー。
   - **ソングパック別進捗一覧**: 各パックごとの曲数・平均スコア・平均定数・進捗率プログレスバー。全曲クリア・全曲AP等の称号バッジ表示。
2. **👑 BEST 40枠一覧 (`b40`)**:
   - 上位40曲の単曲Ratingカードをランキング順（1位〜40位）に一覧表示。
   - 各枠の区分（b10: 枠色ゴールド、b20: 枠色シルバー、b40: 枠色ブロンズ）と加重レート寄与度を明記。
   - 「IV と IV-α の排他処理」適用後の実効値のみを正確に抽出。
3. **🌟 理論値(AP+)記録一覧 (`applus`)**:
   - 難易度 IV / IV-α の理論値（1,010,000点）達成譜面を達成順（No）で管理する専用台帳。
   - **新規AP+の自動記録**: 楽曲一覧でIV以上の理論値を登録した際、本日の日付で自動的に台帳へ追加（ツールバーでON/OFF可能）。
   - **最適化された手動追加**: 「理論値達成済み かつ 台帳未登録」の譜面のみが選択肢に自動抽出されるため、膨大な全曲から探す手間を解消。
   - **未保存バー連動**: 記録の追加・編集・削除時も画面下の未保存バーに連動し、「💾 保存する」でスプシへ一発同期可能。
   - **表示・ソート制御**: 取得日列の表示トグル、No昇順/降順、取得日順、定数順、曲名順ソート、キーワード検索。

## 4. 計算ロジック・ドメインルール（厳守事項）

本ツールのすべての計算結果は、公式仕様および基準スプレッドシートの計算式と100%厳密に一致するよう設計されています。

### ① 単曲Rating計算式
スコア（$P$）および譜面定数（$C$）から算出。販売終了曲（`endOfSale === 1`）は一律 `0.000`。
- **1,008,000 点以上**: $C + 3.4 + \frac{P - 1,008,000}{10,000}$
- **1,004,000 〜 1,007,999 点**: $C + 2.4 + \frac{P - 1,004,000}{4,000}$
- **1,000,000 〜 1,003,999 点**: $C + 2.0 + \frac{P - 1,000,000}{10,000}$
- **980,000 〜 999,999 点**: $C + 1.0 + \frac{P - 980,000}{20,000}$
- **950,000 〜 979,999 点**: $C + 0.0 + \frac{P - 950,000}{30,000}$
- **900,000 〜 949,999 点**: $C - 1.0 + \frac{P - 900,000}{50,000}$
- **500,000 〜 899,999 点**: $C - 5.0 + \frac{P - 500,000}{100,000}$
- **500,000 点未満**: $\max\left(C - 9,999 + P \times \frac{4,997}{250,000},\; 0\right)$

### ② IV と IV-α の排他処理ルール
同一楽曲（`songId`）において `IV` と `IV-α` の両方にスコアが存在する場合、**単曲Ratingが高い方のみを有効**とし、低い方は Rating `0.000`（ランキングおよびBEST 40から除外）とします。

### ③ BEST 40集計と総合Rating
有効な単曲Ratingを降順ソートした上位40曲を以下の加重比率で集計：
- **b10 (1〜10位)**: 合計 $\times 0.06$（寄与度 60%）
- **b11-20 (11〜20位)**: 合計 $\times 0.02$（寄与度 20%）
- **b21-40 (21〜40位)**: 合計 $\times 0.01$（寄与度 20%）
- **総合Rating**: $\text{b10合計} \times 0.06 + \text{b20合計} \times 0.02 + \text{b40合計} \times 0.01$
- **理論値Rating**: 全譜面が理論値（1,010,000点 / 単曲Rating $C + 3.6$）だった場合のBEST 40加重合計値。

### ④ 完成度計算（Completion Point）
- **Basic Completion**: $\frac{\text{単曲Rating}}{C + 3.6} \times 0.925$
- **EX+ Bonus**: スコア100.8万以上で段階的に加算（最大 0.051）
- **Clear Bonus**: AP+: `0.025`, AP: `0.02`, FC: `0.01`, その他: `0`
- **Score of Completion (AD)**:
  - IV-α: $\text{ROUND}(\min(1.0, \text{Basic} + \text{EX+} + \text{Clear}),\; 3)$
  - I〜IV: $\text{ROUND}(\text{難易度係数} \times \min(1.0, \text{Basic} + \text{EX+} + \text{Clear}),\; 3)$
    - 難易度係数: I: `0.7`, II: `0.8`, III: `0.9`, IV: `1.0`
- **Completion Point (AF)**:
  - IV-α: 無条件に AD を採用。
  - I〜IV: 同一楽曲の中で AD が最大（同値なら難易度が高い方）の1譜面のみ AD を採用し、他難易度は `0`。
- **完成度%**: $\frac{\sum AF}{\text{現バージョン全曲理論値上限母数}} \times 100$

### ⑤ タイブレーク仕様
すべてのソート処理において、第1ソート条件が同一値の場合の**第2ソート（タイブレーク）は必ず初期番号（`initId`）の昇順**とします。

### ⑥ 楽曲タイトルと IV-α 専用曲名（`titleAlpha`）仕様
- 元のスプレッドシートにおけるワイルドカード回避用記号「`∽`」は本来の「`~`」に正規化して管理します。
- `βinαrΨ` や `Cristalisia` のように、難易度 `IV-α` で楽曲名が変化する楽曲は `titleAlpha` プロパティを保持し、難易度 `IV-α` 表示時のみ専用曲名を表示します。

## 5. Googleスプレッドシート連携（4シート仕様）

個人スプレッドシート連携では、以下の4シート構成でデータを自動生成・双方向同期します：

1. **`Songs` (楽曲マスタ)**: 1曲1行。曲名、IV-α曲名、ソングパック、バージョン、songId、各難易度の定数およびレベル。
2. **`Scores` (プレイ成績)**: スコアが登録されているチャートのみ軽量保存（チャートID、スコア、クリアランプ、更新日時）。
3. **`TheoryRecords` (理論値記録)**: IV / IV-α のAP+達成記録（No、曲名、難易度、レベル、定数、取得日、チャートID）。
4. **`Config` (設定情報)**: ソングパック並び順、統計対象スコープ、取得日列表示設定、最終同期日時。
