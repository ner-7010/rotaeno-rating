# Rotaeno Rating Tracker (ロテーノ レーティング管理ツール)

## 1. プロジェクト概要と基本方針
本プロジェクトは、スマホ向け音楽ゲーム『Rotaeno（ロテーノ）』のスコア記録・レーティング（Rating）計算・BEST 40枠管理・完成度分析を、PC・スマホ・タブレットのブラウザ上で高速かつ完全無料で動作させるクライアント完結型Webアプリケーションです。

### 基本アーキテクチャ方針
- **完全サーバーレス・外部DB不要**:
  外部APIサーバーやデータベースを契約せず、`index.html` 1ファイル（約200KB）の中に全1,766件の譜面マスタデータと計算エンジン、UIロジックを完全内蔵。
- **ローカルファースト（完全オフライン動作）**:
  スコアデータはブラウザの `LocalStorage` に自動保存。通信環境がない状態でも即座に起動し、1ミリ秒未満で全計算を実行。
- **他端末同期・引き継ぎ**:
  JSONエクスポート/インポート機能、および元のGoogleスプレッドシートへの復元用CSVエクスポート機能を備える。

## 3. 主要なドメインルールと計算ロジック（仕様厳守）

後続の開発や改修を行う際は、以下の計算ロジックを改変・破壊しないこと。

### ① 単曲Rating計算式
スコア（$P$）および譜面定数（$C$）から算出。販売終了フラグ（`endOfSale === 1`）の場合は一律 0。
- **1,008,000以上**: $C + 3.4 + (P - 1,008,000) / 10,000$
- **1,004,000〜1,007,999**: $C + 2.4 + (P - 1,004,000) / 4,000$
- **1,000,000〜1,003,999**: $C + 2.0 + (P - 1,000,000) / 10,000$
- **980,000〜999,999**: $C + 1.0 + (P - 980,000) / 20,000$
- **950,000〜979,999**: $C + 0.0 + (P - 950,000) / 30,000$
- **900,000〜949,999**: $C - 1.0 + (P - 900,000) / 50,000$
- **500,000〜899,999**: $C - 5.0 + (P - 500,000) / 100,000$
- **500,000未満**: $\max(C - 9,999 + P \times (4,997 / 250,000), 0)$

### ② Ⅳ と Ⅳ-α の排他処理ルール
同一楽曲（`songId`）において `IV` と `IV-α` の両方がプレイされている場合、**Ratingが高い方のみを有効**とし、低い方は Rating 0（除外扱い・ランキングから除外）とする。

### ③ BEST 40集計と総合Rating
有効な単曲Ratingを降順ソートした上位40曲を採用:
- **b10 (1〜10位)**: 合計 $\times 0.06$ （寄与度60%）
- **b11-20 (11〜20位)**: 合計 $\times 0.02$ （寄与度20%）
- **b21-40 (21〜40位)**: 合計 $\times 0.01$ （寄与度20%）
- **総合Rating**: $\text{b10合計} \times 0.06 + \text{b20合計} \times 0.02 + \text{b40合計} \times 0.01$
- **理論値Rating**: 全譜面が理論値（1,010,000点 / $C+3.6$）だった場合のBEST 40加重平均（現バージョン値: **17.8860**）。

### ④ 完成度計算（スプシAF列合計）
- **Basic Completion**: $(W / (C + 3.6)) \times 0.925$ （$W$は単曲Rating）
- **EX+ Bonus**: スコア100.8万以上で段階的に加算（最大0.051）
- **Clear Bonus**: AP+: 0.025, AP: 0.02, FC: 0.01
- **Score of Completion (AD)**:
  - IV-α: $\text{ROUND}(\min(1.0, \text{Basic} + \text{EX+} + \text{Clear}), 3)$
  - I〜IV: $\text{ROUND}(\text{難易度係数} \times \min(1.0, \text{Basic} + \text{EX+} + \text{Clear}), 3)$
    - 難易度係数: I: 0.7, II: 0.8, III: 0.9, IV: 1.0
- **Completion Point (AF)**:
  - IV-α: 無条件に AD を採用。
  - I〜IV: 同一楽曲の中で AD が最大（同値なら難易度が高い方）の1譜面のみ AD を採用、他は 0。
- **現バージョン最大値**: IV または IV-α で販売終了でない譜面の総数 = **460**。
- **完成度%**: $(\sum AF / 460) \times 100$

### ⑤ ソート仕様
第1ソート条件に関わらず、**第2ソート（タイブレーク）は必ず初期番号（`initId`）昇順**とする。
- デフォルト: `initId` 昇順
- ソングパック順: ソングパック順序（ゲーム公式順／カスタム並び替え順）昇順 -> `initId` 昇順
- タイトル順: 楽曲名昇順（A-Z・50音順、`localeCompare`） -> `initId` 昇順
- 単曲レート順: 有効Rating（`effectiveRating`）降順 -> `score` 降順 -> `initId` 昇順
- バージョン順: `version` 降順（セマンティック比較） -> `initId` 昇順
- 定数順: `constant` 降順 -> `initId` 昇順
- スコア順: `score` 降順 -> `initId` 昇順

### ⑥ スコア入力とクリアステータス連動仕様
- **理論値連動（1,010,000点 = AP+）**:
  - スコアに `1010000` を入力した際、クリア状況は自動的に `AP+` に設定される。
  - ランプ選択で `AP+` をタップした際、スコアに自動的に `1010000` が入力される。
  - スコア 1,010,000 点でランプが `AP` と表示される不整合を防ぐため、保存データやマスタデータの読み込み時にも `1010000` のステータスは `AP+` に自動補正される。

### ⑦ 削除曲（販売終了譜面）の表示・フィルタ仕様
- **表示**: 販売終了フラグ（`endOfSale === 1`）の譜面は、単曲Rating表示部に `(IV除外)` と同様の赤文字で `(削除曲)` と明記される。
- **フィルタ機能**: 並び替えバー右端に「削除曲を表示」チェックボックスを設置。
  - デフォルト: **ON**（削除曲も含めて全件表示）
  - OFF: 削除曲（全16譜面）を楽曲リストから除外非表示

### ⑧ 楽曲タイトルの正規化（「∽」から「~」への復元）
- 元のGoogleスプレッドシートにおいて「~」がワイルドカード検索文字として誤動作するのを回避するために「∽」で代用されていた楽曲タイトル（例: `Avataar ~Reincarnation of Kalpa~`, `Psalms ~魂の還るばしょ~`）について、本ツールでは制約がないため本来の「`~`」に一括置換・正規化済み。

### ⑨ 検索・並び替え・絞り込みのモーダル化とフローティングボタン
- **課題解消**: 楽曲リストが1,700件以上あるため、下部にスクロールした際に条件変更のためにページ上部へ戻る手間を解消。
- **フローティングトリガー（FAB）**: ヘッダー直下の青色body領域の中央（`left: 50%; transform: translateX(-50%);`、`z-index: 95`）に「☰ 絞り込み」ボタンを常時固定配置。
  - 右側のスコア/Rating表示や左側の曲名と被らないよう、カードの真ん中に配置。
  - 初期表示時にも1枚目のカードと被らないよう、リスト上部に適度な余白を確保。
  - ヘッダーの高さ（端末ごとに可変）を動的に測定し、ヘッダー直下の青色body領域にぴったり追従。
  - 何かしらのフィルタ（検索、特定難易度、定数、スコア順など）が有効な場合はドットバッジが点灯。
  - 楽曲一覧タブ表示時のみ表示され、他タブ選択時は非表示。
- **モーダル表示**: 「☰ 絞り込み」ボタンをタップすると、検索・並び替え・難易度・定数/ステータス絞り込みがひとまとめになったモーダルが開く（該当件数もモーダル内に表示）。
- **難易度の複数選択（マルチセレクト対応）**:
  - `IV` と `IV-α` の同時表示、`III` と `IV` の同時表示など、任意の複数難易度をトグル選択可能。
  - 「全難易度」をタップすると全解除されて全難易度表示にワンタップで戻るほか、選択した難易度を全てOFFにしても自動で「全難易度」に戻る安全仕様。
- **高度な絞り込み機能＆埋め作業用除外フィルター**:
  1. **スコア下限 / 上限**: 指定範囲のスコアを持つ譜面を抽出（上限指定時は未入力の0点譜面を除外）。
  2. **埋め作業向け除外フィルター（チェックボックス）**:
     - **AP+ 除外**: 1,010,000点 / AP+ランプの譜面を除外。
     - **AP 除外**: AP以上の譜面（AP, AP+）を除外（AP埋め作業用）。
     - **FC 除外**: フルコンボ以上の譜面（FC, AP, AP+）を除外（FC埋め作業用）。
     - **EX (100万) 以上除外**: 1,000,000点以上の譜面を除外（EX埋め作業用）。
     - **既プレイ除外**: 登録・プレイ済の譜面を除外し、未プレイ譜面のみを抽出（クリア埋め・新規開拓用）。
  3. **定数下限 / 上限 / 完全一致**: 0.1刻みの定数範囲または特定定数をピンポイント抽出。
  4. **レベル下限 / 上限 / 完全一致**: ドロップダウン（Lv.1〜16）から中間レベル（`10+`, `11+`, `12+`, `13+` 等）を含めて正確に抽出。
- **リセット機能**: モーダル内左下に「条件リセット」ボタンを配置し、上記全フィルター項目を含めワンタップで初期状態（全曲・デフォルト順）に復帰可能。有効なフィルタがある場合はフローティングボタン上のインジケータ（青いドット）が点灯。

### ⑩ 明示的保存フロー（未保存バー・破棄機能・離脱防止）
- **誤入力防止と即時反映**:
  - スコア入力時は即座にLocalStorageを上書きせず、画面上のレート・B40・完成度計算に「仮反映」してシミュレーション。
  - 未保存の変更がある間、画面下部（ボトムナビゲーションバーのすぐ上）に **「● 未保存の変更があります (○曲)」ポップアップバーが常時浮動表示** される。
- **保存・破棄アクション**:
  - **「💾 保存する」**: クリックでLocalStorageに確定保存され、トースト通知とともにバーが格納される。
  - **「破棄」**: クリックで確認ダイアログを挟まず即座に保存前の状態にロールバック。テンポを損なわずに元に戻せる。
- **離脱防止ガード**: 未保存変更がある状態でブラウザタブを閉じたりリロードしようとすると、`beforeunload` による確認ダイアログが発火し、誤操作によるデータ消失を防止。

### ⑪ スコア欄の直接テキスト編集（PC向け最適化）
- **直接入力 & 部分選択**:
  - モーダル内のスコア表示部が通常の `<input type="text">` に対応。
  - マウスドラッグで下数桁（例: `02`）だけを選択して直接 `57` と打ち直す等の部分編集が可能。
- **キーボード操作**:
  - モーダルを開いた瞬間にスコア入力欄に自動フォーカス＆全選択され、即座にキーボード入力が可能。
  - 数値入力後に `Enter` キーを押すだけで即座に「決定」できるショートカットに対応。
- **双方向連動**:
  - キーボード直接入力と、画面上のテンキー・クイックボタン・AP+連動ロジックがリアルタイムに完全同期。

### ⑫ 楽曲カードの新規追加・ステージング管理
- **新規楽曲の登録機能（データ管理タブ）**:
  - **曲名** (`title`): 必須項目。
  - **ソングパック** (`pack`): ゲーム内画面のソングパック並び順（本編・サイド・コラボ・Virtual/Singer・ソングパック・星間航行・シングルの全60パック順）と完全同一の順序でコンボボックス（`<datalist>`）にサジェスト表示。任意の手打ち入力も可能。また、既存データの表記ゆれ（スペースの個数や大文字小文字など）もゲーム内の正式表記に正規化統一。
  - **バージョン** (`version`): 最新バージョンが自動挿入され、過去バージョンもサジェストから選択可能。
  - **5難易度の定数入力 (`I`, `II`, `III`, `IV`, `IV-α`)**:
    - `I` 〜 `IV` は必須、`IV-α` は任意（空欄の場合はα譜面は生成されず4譜面構成）。
  - **レベル自動算出ロジック**:
    - 定数入力に連動して、各難易度のレベル表示バッジがリアルタイムに更新（例: `7.5` $\to$ `Lv.7`, `10.5` $\to$ `Lv.10`, `10.6` $\to$ `Lv.10+`, `13.7` $\to$ `Lv.13+`）。
    - 判定ルール: 定数 $< 10$ は小数点以下切り捨て、定数 $\ge 10$ かつ小数第1位が 0.6 以上の場合は `+` 表記。
- **ステージング（未保存）フロー**:
  - 「＋ カードを作成してリストに追加」を押すと、フォーム直下に「追加予定の楽曲（未保存）」としてカードが一覧表示。
  - 連続して何曲も追加してから一気に保存することも、1曲だけ追加して保存することも可能。
  - ステージング中のカードには「✕ 取消」ボタンが付き、間違えた曲を個別に取り消し可能。
  - 画面下部のフローティング未保存バー（`#unsavedBar`）が自動で「未保存の変更があります (追加 ○曲)」と連動表示。
  - 「💾 保存する」で `localStorage`（`rotaeno_custom_songs_v1`）に正式コミット。
  - 「破棄」で確認ダイアログなしで即座にキャンセル。
- **シームレスな全システム連動**:
  - 追加された楽曲は楽曲一覧、フィルタ、ソート、スコア入力、単曲レート、BEST 40、完成度（理論値・上限母数）、CSV出力、JSONバックアップに完全統合。
  - データ管理画面には「📁 登録済みカスタム楽曲」一覧が表示され、いつでも個別削除が可能。

### ⑬ ソングパック管理・並び替え（ドラッグ＆ドロップ ＆ 上下矢印）
- **ソングパックの追加と並び替え（データ管理タブ）**:
  - **新規パックの追加**: 入力欄に任意のソングパック名を入力して「追加」ボタンを押すと、リストに新パックを追加。
  - **上下矢印ボタン（`▲` / `▼`）**: タップするだけで1つ上または下と順序を直感的に入れ替え。スマートフォン・タブレット等のタッチ端末でも確実に並び替え可能。
  - **ドラッグ＆ドロップ対応（PC / モバイル両対応）**:
    - PC環境: HTML5 Drag & Drop により各行をスムーズに掴んで移動。
    - モバイル環境（iPhone / iPad / Android）: ドラッグハンドル（`☰`）のタッチイベント追従により、指で掴んで直感的に入れ替え可能。
  - **削除機能（🗑️）**: 不要になったパックをリストからいつでも除外可能。
  - **ゲーム初期順に戻す**: ワンクリックでゲーム公式の全60パックの順序にいつでもリセット可能。
- **未保存バー・永続化との連動**:
  - ソングパックの追加や順序変更を行うと、即座にコンボボックス（`<datalist>`）へリアルタイム反映。
  - 画面下部の未保存フローティングバー（`#unsavedBar`）に「未保存の変更があります (パック順序)」と連動表示。
  - 「💾 保存する」を押すと `localStorage`（`rotaeno_pack_order_v1`）に確定保存。
  - 「破棄」を押すと保存前の並び順に一括ロールバック。
  - JSONバックアップ（エクスポート／インポート）時にもカスタムソングパック順序が完全保持される。

### ⑭ 埋め作業用除外フィルター ＆ マイページ（疑似ページ遷移・統計・IV以上理論値記録）
- **埋め作業用除外フィルター4種（楽曲一覧 絞り込みモーダル）**:
  - **AP除外**: AP/AP+済みの譜面（スコア1,010,000含む）を除外し、未AP埋めに集中可能。
  - **FC除外**: FC/AP/AP+済みの譜面を除外し、未フルコン埋めに集中可能。
  - **EX(100万)以上除外**: 1,000,000点以上の譜面を除外し、EX未満の底上げ対象を一発抽出。
  - **既プレイ除外**: スコア登録済みまたはランプ獲得済みの譜面をすべて除外し、未プレイ曲のみを網羅抽出。
- **マイページタブへの集約 ＆ 疑似ページ遷移サブナビゲーション**:
  - フッタータブを「BEST 40」から「👤 マイページ」へ昇格。タブを乱立させず、マイページ内で3つのサブビューをタブ切り替え（疑似ページ遷移・スムーズなCSSフェードアニメーション）:
    1. **📊 総合進捗・統計**: 埋めたくなる思考をくすぐる全方位の進捗可視化。
    2. **👑 BEST 40**: 従来のB40対象曲リスト・枠内平均・完成度・CSV出力。
    3. **🌟 理論値(AP+)記録**: IV / IV-α難易度の全理論値達成記録テーブル。
  - 各サブビューにはワンタップで総合進捗に戻れるクイック戻るボタン（`← 総合進捗に戻る`）を配置。
- **総合進捗・統計サブビュー（埋めたくなる思考を刺激する統計機能）**:
  - **全体サマリー＆ランプ分布**: 全譜面数に対するAP+ / AP / FC / EX / CLEAR / 未プレイの獲得数・割合をビジュアルカード化。
  - **スコア統計指標**: 登録全曲の平均スコア、IV / IV-αのみの平均スコア、IV未AP+残数をリアルタイム計算（固定値で限界があり実力指標として不適当な「平均定数」は排除）。
  - **難易度別クリア状況テーブル**: IV-α, IV, III, II, I ごとの総譜面数、AP+・AP・FC・EX各達成数、およびプログレスバー表示。
  - **レベル別埋まり状況（Lv.1 〜 Lv.14+）**: レベル別のAP+/AP/FC/EX/未プレイの構成比率をスタック型マルチカラーゲージで視覚化。
  - **ソングパック別進捗カード（ゲーム順全60パック）**:
    - 各パックの総曲数、AP+数、FC数、平均スコア、達成度バー。
    - 全曲AP+で「👑 全AP+」、全APで「🌟 全AP」、全FCで「🔷 全FC」、全クリアで「✅ 全曲クリア」のコンプリートバッジが自動付与。
    - 「楽曲一覧で絞り込み 🔍」ボタンで、当該パックの楽曲一覧へワンタップでジャンプ。
- **IV以上 理論値(AP+)記録サブビュー**:
  - **記録テーブル項目**: `No`, `曲名`, `難易度`, `レベル`, `定数`, `AP+取得日`, `操作 (編集/削除)`.
  - **初期データ**: ユーザーの実績データ110曲分（`default_ap_plus_records.json`）を初期投入・完全マスタマッチ。
  - **取得日列の表示/非表示トグル**:
    - 「取得日列を表示」チェックボックス（`chkShowApPlusDate`）を装備。
    - 他者への配布時や取得日を記録しないプレイヤー向けに、ワンクリックで取得日列を非表示化可能（設定は `localStorage` に即時永続化）。
  - **レコード追加・編集モーダル（`#apPlusModal`）**:
    - 楽曲（IV / IV-α）選択ドロップダウン、難易度・レベル・定数の自動取得連動、日付ピッカー、No指定機能。
  - **スコア自動同期機能（`⚡ スコア自動同期`）**:
    - スコア管理側で 1,010,000点 または AP+ を獲得した IV / IV-α 譜面を自動検出し、理論値記録に未登録のものがあればワンクリックで一括追加（当日の日付を自動設定）。
  - **データ永続化とバックアップ**:
    - `rotaeno_ap_plus_records_v1` として `localStorage` に永続化。
    - JSONバックアップ（エクスポート／インポート）にも完全対応。

### ⑮ 達成状況・統計の難易度範囲切り替え（全難易度 ⇄ IV / IV-α のみ）
- **背景**:
  - レーティング対象や完成度枠は高難易度（IV以上）が主体であり、III以下をプレイしない上級者・理論値勢にとっては、全難易度合算の統計だと進捗率やソングパックのコンプリート状況が薄まってしまう問題を解決。
- **集計対象切り替えセレクター（ピル型トグル）**:
  - マイページ「総合進捗・統計」最上部に `[ 🌐 全難易度 (全1,766譜面) ]` と `[ ⚡ IV / IV-α のみ (全467譜面) ]` の切り替えトグルを配置。
  - 選択状態は `localStorage`（`rotaeno_stats_scope_v1`）に自動永続化され、リロード後も前回の状態を維持。
- **動的集計連動**:
  - **全体登録進捗＆クリアランプ内訳**:
    - 「IV/IV-αのみ」モード時は母数を全467譜面として、IV帯のAP+/AP/FC/EX/未プレイの正確な達成比率を算出。
    - **AP集計仕様**: AP（All Perfect）の達成数には、上位ランプである AP+（理論値）の数も合算（音ゲーの通例仕様）。
  - **平均・残数指標（メタカード）**:
    - IVモード時は「IV登録 平均スコア」「IV/IV-α 未AP残数」「IV/IV-α 未AP+残数」に最適化（ジャンプカード側と重複していた「IV理論値達成率」を排除し、実用的な未AP残数へ刷新）。
  - **難易度別クリア状況テーブル**:
    - IV/IV-αのみモード時は `IV-α` と `IV` の2行にすっきり絞り込み。
  - **レベル別埋まり状況**:
    - IV譜面が存在するレベル帯（Lv.9〜Lv.14+）にフォーカスし、各レベルのIV譜面だけの埋まり状況を正確にスタックバー表示。
  - **ソングパック別進捗一覧（全60パック）**:
    - 各パックの総曲数・進捗・平均点を**当該パックのIV/IV-α譜面のみ**を母数として算出。
    - そのパックのIV譜面をすべてAP+していれば `👑 全AP+`、すべてAPしていれば `🌟 全AP` のコンプリートバッジが正しく点灯！
    - パックカードの「曲一覧へ 🔍」を押すと、自動的に難易度フィルターもIV/IV-αに絞り込まれた状態で楽曲一覧へジャンプ。

### ⑯ ソート連動アコーディオン折りたたみ帯（曲一覧セクション）
- **背景 & 目的**:
  - 全1,766譜面（436曲）の膨大な楽曲リストにおいて、目的の曲・パック・レベル・グレードへ素早く到達できるよう、選択中のソート順に合わせた「折りたたみ可能なアコーディオンセクション帯」を実装。
- **5大ソート対応の最適化グループ化**:
  1. **ソングパック順 (`PACK`)**:
     - 公式／カスタムのゲーム内パック順（全60パック）ごとに折りたたみ帯を生成。
     - 各パック内に属する譜面が初期ID順にグループ化。
  2. **タイトル順 (`TITLE`)**:
     - 「あ行・か行・さ行・た行・な行・は行・ま行・や行・ら行・わ行」
     - 「A - E」「F - J」「K - O」「P - T」「U - Z」
     - 「数字 (0 - 9)」
     - 「記号 (!@@k, ^/7, -ish, 《》, [] など)」
     - 「漢字, その他 (中国語タイトル、四字熟語、韓国語ハングルなど)」
     - 全436タイトルの特殊読み・漢字表記（57曲の例外含む）を完全網羅して分類。
  3. **バージョン順 (`VERSION`)**:
     - 実装バージョン（最新 Ver 2.99.0 〜 Ver 1.0.0 まで全58バージョン）の降順でグループ化。
  4. **定数順 (`CONST`)**:
     - レベル単位（Lv.14, Lv.13+, Lv.13, Lv.12+, ... Lv.1 の全18レベル）でグループ化。
     - グループ内は譜面定数の降順（同定数はスコア降順）で整理。
  5. **スコア順 (`SCORE`)**:
     - Rotaeno公式スコアグレードに応じた12段階のティアグループ化：
       - `1,010,000点 (理論値)`: 虹Ex+虹ゲージ (AP+)
       - `1,008,000 ~ 1,009,999点`: 虹Ex
       - `1,000,000 ~ 1,007,999点`: 橙Ex
       - `980,000 ~ 999,999点`: S+
       - `950,000 ~ 979,999点`: S
       - `900,000 ~ 949,999点`: A+
       - `850,000 ~ 899,999点`: A
       - `800,000 ~ 849,999点`: B
       - `700,000 ~ 799,999点`: C
       - `600,000 ~ 699,999点`: D
       - `500,000 ~ 599,999点`: E
       - `0 ~ 499,999点 (未プレイ含む)`: F
       - 各グループヘッダーには専用カラーのグレードバッジを表示。
  6. **通常順 (`DEFAULT`) / レーティング順 (`RATING`)**:
     - 帯なしのフラットな高速リスト表示を維持。
- **クイック開閉ツールバー**:
  - グループ化ソート選択時のみ、リスト上部にツールバーが自動出現。
  - 「現在のグループ数と対象譜面数（例：`60 グループ (1,766 件)`）」をリアルタイム表示。
  - 「📂 すべて展開」「📁 すべて折りたたむ」のワンタップ一括操作ボタンを完備。
  - ソート変更や絞り込みリセット時には折りたたみ状態をスマートに自動リセット。

### ⑥ Googleスプレッドシート連携（個人クラウド同期）
外部データベース不要で、ユーザー自身のGoogleスプレッドシートを個人DBとして活用する双方向同期機能。コピペ作業は一切不要で、アプリ内のボタンを1タップするだけで通信・同期が完了します。
- **4シート分離構造**:
  1. **`Songs` (楽曲マスター)**: 1曲1行（曲名、パック、バージョン、songId、各難易度の定数・レベル）。初期曲と追加曲を一元管理。
  2. **`Scores` (プレイ成績)**: 入力済みスコアのみを軽量保存（チャートID、スコア、クリアランプ、更新日時）。
  3. **`TheoryRecords` (理論値記録)**: IV以上のAP+記録一覧（No、曲名、難易度、達成日、備考）。
  4. **`Config` (設定データ)**: パック並び順、統計対象スコープ、日付表示設定、最終同期日時。
- **Google Apps Script (GAS) 連携**:
  - `gas_sync.js` をスプシの「拡張機能」>「Apps Script」に貼り付けてウェブアプリとしてデプロイ。
  - アプリの設定画面から「📋 GASコードをコピー」でワンクリック取得可能。
  - スマホからでもCORS制限なく高速に双方向同期を実行（`text/plain` POST / GET）。
